## Следующая проверка пользователем

1. Завершить игру/сервер. На обоих ПК в тестовом профиле Vortex отключить прежний True Coop,
   установить новый ZIP, включить оба ESP и выполнить Manual apply (Deploy).
2. Обновить сервер этим же архивом. Address Library 1.7.104 остаётся установленной;
   существующая кнопка запуска Vortex подходит.
3. Сначала использовать одинаковые активные плагины/порядок: проверить подключение, видимость,
   экипировку, лут NPC, передачу предметов, смену локации и переподключение.
4. Сравнить фактические количества предметов у обоих. Это не подтверждённая полная защита от дюпа:
   два разных одновременных запроса на один предмет требуют следующих изменений.
5. Для отрицательного DLC-теста использовать только отдельный новый профиль/персонажа:
   лишний активный плагин у одного участника должен дать понятный Content mismatch.
   Поддержка разных активных DLC в ограниченном режиме ещё не готова.

При ошибке сохранить точный текст сообщения и списки активных плагинов. Проверку не отключать
на основном прохождении. Основные сохранения не использовать для испытаний новой логики.
