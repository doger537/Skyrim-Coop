# Локальная проверка квестовых выдач — 1.7.104.0

Это экспериментальная диагностическая сборка для одного клиента. Нужен новый персонаж; друг не требуется. Автоматическая раздача наград второму игроку ещё не включена. Проверка не заменяет совместный игровой тест общей загрузки.

1. Закрой Skyrim. В Vortex активируй профиль **TrueCoop Quest Audit** с отдельными сохранениями и настройками.
2. Через **Mods → Install From File** установи выданный архив `SkyrimTrueCoop-AE-quest-audit-1.7.104-….zip`. Это полный пакет; старый кооперативный мод в этом профиле отключи, чтобы одновременно работала одна сборка.
3. Включи Address Library для 1.7.104, текущий рабочий SKSE и, если используешь его, уже исправленный Engine Fixes для 1.7.104. Включи новый диагностический пакет.
4. В **Plugins** включи `SkyrimTogether.esp`, `SkyrimTogetherQuestPatches.esp`, `TrueCoopQuestProbe.esp`. Выполни **Deploy / Manual apply (Deploy)**.
5. Открой папку установленной игры, затем **Data → SkyrimTogetherReborn**. Запусти **Start-QuestAudit.cmd**. Оставь его окно открытым до конца теста. Сервер и отдельная папка сохранений создаются автоматически. Если предыдущий запуск был прерван, сначала закрой игру и запусти **Restore-QuestAudit.cmd**.
6. В главном меню игры переключи раскладку на английскую, открой игровую консоль клавишей **~ / Ё**, введи `coc qasmoke` и нажми Enter. Закрой консоль и дождись появления в комнате. **Обычное сохранение не загружай.**
7. Открой сетевое меню **правым Ctrl**. Подключись к адресу **127.0.0.1:38649**, пароль **questaudit**. Дождись успешного подключения.
8. В игровой консоли введи `startquest TrueCoopRewardProbe`. Закрой консоль на 5 секунд.
9. Снова открой консоль и введи `cqf TrueCoopRewardProbe GrantForAudit`. Закрой консоль на 5 секунд. Ожидается уведомление **TrueCoop quest probe: gold delta 17**.
10. Для контрольной проверки введи `player.additem f 17`, затем закрой консоль на 5 секунд. Это отдельная обычная выдача; она не должна получить источник диагностического квеста.
11. Выйди из игры обычным способом. Дождись сообщения **Original SkyrimCustom.ini restored** в окне запускателя, затем его можно закрыть. Напиши в чат, что тест завершён и было ли уведомление о 17 золота. Логи я прочитаю с этого компьютера сам.

Каждый запуск создаёт отдельную серверную базу. Она не заменяет ваш обычный мир. Доказательства сохраняются в `%LOCALAPPDATA%\SkyrimTrueCoop\QuestAudit\run-…`: клиентский журнал, Papyrus и журнал сервера. Скрипт никуда их не отправляет.

После проверки вернись в основной профиль Vortex и задеплой его обычный набор модов. Диагностическая сборка не нужна для дальнейшей обычной игры.
