# Реестр Anniversary Upgrade (2021)

74 Creations. Это перечень поставки, а не подтверждение сетевой совместимости.
Новые платные Creations после выпуска Upgrade не включаются в него автоматически.
Dawnguard.esm, HearthFires.esm, Dragonborn.esm входят в SE, отдельно от этих 74.

Источник состава: [Bethesda](https://help.bethesda.net/app/answers/detail/a_id/54327/).
Имена сверены с [LOOT masterlist](https://github.com/loot/skyrimse/blob/master/masterlist.yaml).
BSA ниже — ожидаемое имя; реальные файлы, флаги ESL и точные MAST нужно прочитать из установки.
Зависимости не выдумываются: для каждой записи пока статус **требуется аудит установленного TES4**.
Хеши игр в репозитории отсутствуют; получать/распространять файлы игры этот код не будет.

Для каждой строки сетевые проверки предметов, NPC, магии, локаций, контейнеров, квестов,
повторного входа и сохранения мира **не выполнены в игре**. Неприменимость сценария также
должна подтверждаться анализом записей. Машиночитаемый реестр: [catalog.json](catalog.json).
