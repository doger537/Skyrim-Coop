# Продолжение AE: постоянное состояние

## Контрольная точка G — хранилище

Добавлен отдельный `TrueCoopState`, без зависимости от движка. SQLite 3.46.0
закреплена в xmake. Один сервер эксклюзивно владеет файлом мира; WAL и
`synchronous=FULL` используются для атомарной фиксации. Каждая запись защищена
SHA-256 от ключа, ревизии и payload. Пакет изменений либо фиксируется целиком,
либо откатывается. Запись с устаревшей ревизией не заменяет новую.

Первичная проверка: 33 Catch2-теста, 665 assertions, exit 0. Есть отдельные
сценарии открытия существующего мира, конфликта ревизии, ошибки внутри пакета,
повреждения payload и попытки второго сервера открыть тот же файл. Чужая БД и
неизвестная версия схемы отклоняются. Файлы не пересоздаются для обхода ошибки.

Эта точка проверяет хранилище. Подключение игровых сервисов выполняется следующим
пакетом. Это ещё не доказательство сохранности игрового сейва или всей кампании.

Основание настроек: [SQLite PRAGMA](https://sqlite.org/pragma.html), режимы locking,
journal и synchronous. Не копировать только основной файл работающей WAL-базы:
для резервирования остановить сервер или использовать SQLite backup API.
