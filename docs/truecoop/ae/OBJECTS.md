# C — сетевые объекты AE

**Реализовано, игровая проверка не выполнена**: `ModSystem::GetGameId` больше не
маскирует повреждённый BaseId. Общий `ComposeRuntimeForm` проверяет 24 бита обычного
плагина, 12 бит ESL, границы слотов и не допускает FE/FF как обычный слот.
Неизвестные плагины по-прежнему не отображаются в Skyrim.esm.

Этот путь используется существующими сервисами предметов, экипировки, NPC, магии,
активации, контейнеров и локаций. Не создаётся отдельная система ID для Creations.
Тесты проверяют границы формата; они не доказывают существование формы в игре.

Игровой барьер C: для каждого дополнения из каталога выполнить применимые сценарии
AE-ITEM/NPC/MAGIC/CELL/CONTAINER. Обязательны два игрока у одного объекта/NPC/сундука,
смена владельца при выходе из ячейки и обрыв при переносе предмета. Зафиксировать
суммарное количество вещей до/после, без console-spawn как единственного сценария.

`OperationWindow` не равен транзакции «предмет ушёл из сундука и появился у игрока».
Атомарные конкурентные операции и постоянный мир этим пакетом не реализованы.
Объекты по-прежнему могут удаляться из серверной ECS при уходе последнего игрока.
Для долговременного хранения нужны ключ plugin+localForm+WorldId, транзакционный
журнал, recovery и сверка сейва, а не сохранение временного server entity ID.
