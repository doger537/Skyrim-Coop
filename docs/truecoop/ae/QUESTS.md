# D — общий прогресс, состояние работ

Главное правило остаётся целью: один сюжет и один результат решений для сервера.
Индивидуальные сюжетные ветки и отдельные версии мира не добавляются.

Исправлен конкретный дефект прежней ретрансляции: повторный Started от второго
участника стирал множество уже переданных стадий. Следующий повтор StageUpdate
снова отправлялся группе. `QuestEventHistory` подавляет повтор Started/Stopped,
сохраняет стадии до явного Stopped → Started и разрешает повторяемые задания.
Поздний первый Started также не стирает ранее полученные стадии.
Число стадии не используется для выбора «правильной» сюжетной ветки.

**Реализовано, игровая проверка не выполнена.** Это исправление в существующем
party relay, не готовая общая кампания. История пока живёт в группе в памяти.
Общесерверный постоянный журнал, конфликтующие решения, поколения перезапуска
квестов и безопасный поздний вход не реализованы. Поздний Started после Stopped
без идентификатора запуска всё ещё нельзя отличить от настоящего рестарта.
Misc/None-квесты остаются под прежней экспериментальной настройкой; включать её
для всей AE-поставки без испытаний нельзя.

## Матрица адаптеров

Приоритетные прогоны: Fishing, Saints & Seducers, The Cause, Ghosts of the Tribunal,
Forgotten Seasons, Bittercup, Farming, Bloodchill Manor, Survival Mode, Nchuanthumz.
Остальные 64 записи также требуют анализа QUST/VMAD: имя плагина и наличие оружия
не доказывают отсутствие квестового скрипта. Ни один адаптер пока не объявлен готовым.

Для каждого фактического QUST заполнить:

| Поле | Обязательные сведения |
|---|---|
| Identity | plugin SHA-256 + local QUST FormID, версия ресурсов |
| Prerequisites | masters, начальные стадии, aliases и зависимые globals |
| Events | стадии, Stop/Start, диалоги, сцены, Papyrus fragments, rewards |
| Decisions | взаимоисключающие варианты и одно авторитетное решение |
| Replay | какие операции идемпотентны, какие нельзя повторять при входе |
| Recovery | журнал/поколение/сверка сейва, обрыв до и после фиксации |
| Evidence | два клиента, действия обоих игроков, поздний вход, награды, перезапуск |

Для решений понадобится серверная последовательность операций и сохранённый
результат до рассылки. Для Papyrus требуется анализ реальных скриптов и поведения
движка. Новые хуки и offset-ы без IDA/Ghidra здесь не угадывались.

Alternate Start policy, исключение личных начальных форм и scene guards сохранены.
MAST теперь проверяется для всех активных плагинов, включая актуальные зависимости
USSEP. Конкретный набор ASLAL+USSEP+AE ещё должен пройти AE-START из игрового плана.
