## Что именно доказано

- Все 74 имени проходят отдельные unit-сценарии изменения хеша плагина/BSA,
  отсутствующего плагина и отсутствующего архива. Проверен wire round-trip полного
  профиля (5 базовых + 74 CC), MAST/порядок, неверные/пустые хеши, ресурсы и границы ID.
- Через настоящие локальные сетевые соединения приняты два одинаковых синтетических
  клиента и отклонены неверные схема/build/runtime/пароль/плагины/ресурсы/masters.
  Отклонённый первый клиент не закрепляет свой контракт и не меняет базовый ID.
- NPC с синтетическим CC GameId сохраняет правильное количество вещей после
  повторов пакета и устаревшей эпохи. Проверены отказы старых movement/action epochs.
- Два клиента получают один серверный ID контейнера. Второй устаревший upload не
  перезаписывает содержимое. Две разные операции -1 и повтор первой дают 8 из 10.
  После переподключения второго клиента при первом в ячейке возвращаются 8 вещей
  и актуальный замок. Это проверка снимка в памяти, не дисковой сохранности мира.
- Оба участника группы последовательно продвигают синтетический квест. Повтор
  Started и уже отправленной стадии от другого участника не ретранслируется заново.

Файловые проверки не удостоверяют исправность реальных скриптов, aliases, сцен,
квестовых решений, моделей, эффектов, рыбалки или выживания. Для них остаётся
статус **«Реализовано, игровая проверка не выполнена»**, если соответствующий путь
есть в коде, либо **«Не реализовано»** для отсутствующих подсистем.

Не реализованы: постоянный общесерверный сюжет/решения, безопасный универсальный
поздний replay CC-квестов, атомарная передача последней вещи между двумя игроками,
постоянный мир после ухода всех/перезапуска и проверенный смешанный Limited-профиль.
Конкретные версии ASLAL+USSEP+AE пока не приняты. Steam invite не добавлялся.

Отдельное последующее исправление диагностики клиента: при запрете только SKSE
сообщение больше не перечисляет MO2 как причину. Оно не входит в доказательства
сетевого UI-теста: Windows-клиент здесь не запускался.

## Воспроизведение

```text
xmake config --clean --mode=releasedbg --yes
xmake build SkyrimServerRunner
xmake build TrueCoopProtocolProbe
xmake build TrueCoopContentAudit
xmake run TPTests
python3 Tools/TrueCoop/check_ae_catalog.py
```

В новой пустой рабочей папке запустить собранный сервер с аргументами
`-GameServer:uPort=10582 -LiveServices:bAnnounceServer=false -ModPolicy:bEnableContentCheck=true`.
На Linux рядом должна быть доступна libSTServer.so, на Windows — STServer.dll.
В другой консоли: `TrueCoopProtocolProbe 127.0.0.1:10582`, после `/quit` в серверной
консоли. Повторить на новом сервере/порту со старым флагом false и убедиться, что
несовместимые профили всё равно отклоняются. Не запускать probe на сервере прохождения.
