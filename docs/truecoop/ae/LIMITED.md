# E — Limited Compatibility

Проверенных сочетаний **разного активного контента** пока нет. Allowlist пуста;
расхождения плагинов, masters, ресурсов и библиотек отклоняются. Это проверено
автоматически в обе стороны SE → AE и AE → SE на синтетических манифестах.

| Профиль | Подключение | Игровая приёмка |
|---|---|---|
| AE + AE, идентичный полный активный набор | Строгий контракт допускает одинаковые манифесты | Не выполнена |
| SE + SE, одинаковый общий набор | Строгий контракт допускает одинаковые манифесты | Новая сборка не проверена |
| Владелец AE + владелец SE с одинаковым общим активным набором и ресурсами | Обычный строгий режим; не Limited по DLC | Новая сборка не проверена |
| Разные активные CC-плагины, даже при одинаковом exe | Отказ с именем отсутствующего/лишнего плагина | Не разрешено |
| Одинаковые плагины, разные BSA/скрипты/DLL | Отказ с ресурсом и способом исправления | Не разрешено |

Прежние `SharedContent.ps1`, резервные копии и восстановление сохраняются.
Инструмент подготовки общего SE-профиля не является поддержкой активных AE-квестов
на клиенте, у которого этих дополнений нет. Хеши ресурсов могут выявить оставшиеся
loose-файлы; их нельзя скрывать или игнорировать ради входа.

Чтобы добавить конкретный Limited-профиль, нужны:

1. Идентификатор профиля и закреплённые runtime/build/protocol/файлы обеих сторон.
2. Явный перечень разрешённых различий и доказательство отсутствия сетевых ссылок
   на недоступные формы, ресурсы, Papyrus-классы и сюжетные состояния.
3. Правила инвентаря, входа в ячейки, квестов и сохранений. Отсутствующие предметы
   не подменяются ванильными, DLC не передаются по сети.
4. Два настоящих клиента, регрессия и запись результатов для каждого исключения.

До выполнения этих условий новый профиль не должен менять `Compare` или его
защитные проверки. Сервер не определяет покупку Upgrade по версии exe, имени
профиля или сообщению клиента о лицензии. Steam DRM остаётся вне этих изменений.
