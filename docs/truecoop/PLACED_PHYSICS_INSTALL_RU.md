# Физика объектов и согласованные сейвы — экспериментальная сборка

Для двух игроков с SkyrimSE.exe **1.7.104.0**, одинаковыми активными плагинами
и ресурсами. Обоим и серверу нужна одна новая версия пакета. Альтернативное
начало не изменялось. Игровые и автоматические тесты отложены по просьбе
пользователя: сборка не подтверждает отсутствие вылетов и рассинхрона.

## Что добавлено

- Поиск и синхронизация подвижных физических тел заранее расставленных
  объектов в загруженных ячейках. Передаются положения, полные повороты
  и скорости; владелец симуляции назначается сервером. Приоритет у хоста,
  в не загруженной им локации возможна делегация второму игроку.
- Перед общим сохранением оба клиента под паузой применяют единый физический
  снимок и повторно считывают результат. Пока оба не подтвердили совпадение,
  ESS не записываются. При неподдержанном объекте операция отменяется.
- После общей загрузки этот же снимок восстанавливается до снятия паузы.
  К ESS и SKSE добавлен обязательный файл **TCPHYS** с привязками объектов.
  Сервер сохраняет сам снимок и проверяет его SHA-256.

Сохраняются прежние ускоренные квестовые выдачи/списания, управляемый дроп,
ragdoll NPC, время, погода, сон и маркеры. Их ограничения описаны в документах
пакета; эта версия не объявляется выполнением всего первоначального ТЗ.

## Установка

1. Закройте игру и сервер. Сохраните копии предыдущего ZIP, обоих наборов
   сохранений и всей папки данных остановленного сервера. Старую базу не удаляйте.
2. В тестовом профиле Vortex отключите старый пакет TrueCoop/Skyrim Together.
   Установите **новый ZIP** через Install From File, включите и нажмите Deploy.
   Друг делает то же самое с тем же ZIP.
3. В Plugins должны быть включены `SkyrimTogether.esp`,
   `SkyrimTogetherQuestPatches.esp` и `TrueCoopWorldState.esp`.
   Address Library нужна под 1.7.104.0. Совместимость других DLL проверяйте отдельно.
4. У владельца сервера откройте
   `Data/SkyrimTogetherReborn/config/STServer.ini`. Если файла ещё нет,
   создайте папку `config` и этот текстовый файл. В существующей секции
   `[Persistence]` замените только `sWorldPath`; если секции нет, добавьте:

   ```ini
   [Persistence]
   sWorldPath=Data/TrueCoop-physics-20261119/world.sqlite3
   ```

   Это отдельная **новая** кампания. Протокол изменился, схема базы теперь 6;
   база предыдущей сборки намеренно не конвертируется. Для возврата к ней
   используйте её исходную версию мода и соответствующие сейвы.
5. Обоим создайте новых тестовых персонажей, пройдите пролог отдельно.
   Запуск игры — `Data/SkyrimTogetherReborn/Play-AE.cmd`, сервера у одного —
   `Start-AE-Server.cmd`. Подключитесь к нему вашим уже настроенным способом,
   создайте группу из двух игроков. Сюжет по-прежнему ведёт хост.

## Сохранение и загрузка

Хост вводит `/coop-save` в сетевом чате либо использует перехватываемое модом
быстрое/ручное сохранение. Не закрывайте открывшуюся паузу: идёт сбор,
выравнивание и проверка физических поз. На большой локации это занимает
несколько кадров или дольше. Дождитесь сообщения с номером общего сейва.

Общая загрузка: **`/coop-load N`** у хоста, где N — этот номер. Оба клиента
загрузят свои файлы и переподключатся. Игра продолжится после подтверждения
физики обоими. F9 не является командой согласованной загрузки всей группы.

Для переноса/резервного копирования общего checkpoint храните вместе:

- у каждого игрока — одноимённые `.ess`, `.skse` при наличии SKSE и `.tcphys`;
- у хоста сервера — всю базу этой кампании, скопированную при остановленном сервере.

Не передавайте свой ESS другу: в общей паре у каждого остаётся его персонаж.
При сообщении об отмене смотрите журнал. При неудачном выравнивании **после
загрузки** сервер остановится с незавершённым восстановлением; сохраните файлы
и перезапустите ту же сборку для повтора. Не стирайте базу и не снимайте проверки.

## Границы

Обходятся загруженные ячейки, а не весь незагруженный Скайрим. Физика модов
с произвольными Havok-классами не гарантируется. Пределы: 8 192 расставленных
ссылки в кампании, 8 192 записи в физическом checkpoint, 32 подвижных тела
на объект; управляемый дроп по-прежнему ограничен 64 объектами. Превышение
лимита или несовпадение нативных float-поз отменяет checkpoint.
Полный solver Havok и незахваченные физические толчки гостя отдельно не передаются.
Мягкий бюджет движковой работы не является гарантией нулевых микрофризов.

Техническая схема и фактические проверки Ghidra: `PLACED_PHYSICS_CHECKPOINTS.md`.
