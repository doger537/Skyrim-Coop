# Проверочная сборка: часы, погода и сетевые перемещения

Для двух Steam SkyrimSE.exe 1.7.104.0 с одинаковым активным контентом AE.
Полный идентификатор комплекта указан в TrueCoop-AE-Info/BUILD.json.
Это новая сборка клиента И сервера; quest-relay-test2 с ней не соединяется.

## Перед установкой

1. Завершите обе игры и сервер. Сохраните прежние ZIP, конфигурацию сервера и
   тестовые сохранения. Рабочую базу кампании копируют только после остановки сервера.
2. Если включали CommonSE, сначала восстановите Creations старым Restore-Creations.cmd
   до смены профиля и Deploy. Резервную папку TrueCoop-CommonSE-Backup не удаляйте.
3. Создайте отдельный тестовый профиль Vortex с отдельными сохранениями.
   Отключите в нём прежние TrueCoop/Skyrim Together и CommonSE-Tools.

## Установка и запуск

1. Оба игрока устанавливают один и тот же новый ZIP через Install From File,
   включают его и выполняют Deploy. Включите SkyrimTogether.esp и
   SkyrimTogetherQuestPatches.esp в Plugins.
2. Оставьте Address Library для 1.7.104.0 и соответствующий SKSE. Если используете
   Engine Fixes, оставьте проверенную официальную 7.0.21-beta5 у обоих,
   а прежнюю 7.0.20 выключенной.
3. Запускайте Data/SkyrimTogetherReborn/Play-AE.cmd. Этот запуск сохраняет Creations.
   Сервер запускает один участник через Start-AE-Server.cmd в той же папке.
   Старый сервер quest-relay-test2 для этой проверки не подходит.
4. Создайте новых тестовых персонажей с одинаковым началом и исходным прогрессом.
   Завершите пролог офлайн, сохранитесь, затем подключайтесь и создавайте группу.
   В этой ветке действует проверка общего журнала кампании: разные исходные стадии
   могут вызвать отказ подключения. Пример реестра проверенных адаптеров пуст.

## Что проверять вдвоём

- Часы: подключение, отключение, другой хост, повторное подключение; сравните часы
  через 5 секунд после входа и после минутной серверной синхронизации.
- Погода: лидер задаёт погоду мира; участник восстанавливает её при повторном запросе,
  карта не должна подменять её. Проверьте разные локации, вход/выход из интерьера
  и смену лидера: присутствие его модели рядом больше не требуется.
- NPC: переход между ячейками и смена владельца. Для отслеживаемых копий проверяется поколение владельца;
  отсутствие всех ошибок Havok, мебели и ragdoll ещё не подтверждено.

## Что этот ZIP не завершает

Полная физика дропа и тел, сохранение всего мира по QuickSave, совместный сон,
удержание NPC в диалоге гостя, постоянные маркеры и безопасные награды всех квестов
ещё не реализованы. Нельзя включением bEnableItemDrops получить недостающий протокол
физики и постоянных ID предметов. Планы и границы описаны в приложенных документах.

Проверка сборки и автоматические тесты отдельно от реальной совместной игры.
Результат двух настоящих клиентов и замеры времени кадра для этой версии ещё нужны.
