## Чего проверки не доказывают

Синтетические клиенты не запускают Skyrim, Havok или графы анимаций. Реальный внешний вид,
смерть/оживление, езда, переходы и смена владельца NPC ещё не проверены в двух играх на этой
версии. Нулевой рассинхрон не подтверждён. Адаптер Alternate Start частичный, текущая
комбинация ASLAL/USSEP не установлена и не проверена в игре. Разные активные DLC не поддержаны.
Полное ТЗ не выполнено; точные изменения и ограничения — [ITERATION_3.md](ITERATION_3.md).

## Что сделать после возвращения

1. Закрыть игру и сервер на обоих ПК. Сохранить прежний ZIP. В тестовом профиле Vortex
   отключить старый True Coop / Skyrim Together, установить новый ZIP через Install From File,
   включить мод, оба ESP и выполнить Manual apply (Deploy). Address Library оставить.
2. На сервере тоже использовать файлы нового ZIP. Запускать прежним инструментом Vortex:
   путь `Data/SkyrimTogetherReborn/SkyrimTogether.exe` остаётся тем же.
3. Сначала использовать одинаковые активные плагины и их порядок, тестовых персонажей,
   создать группу. Проверить ходьбу/бег/прыжки, повороты, оружие и бой с NPC. По очереди
   выйти из ячейки и отключиться, затем вернуться: проверить положение, анимации, жизнь
   и инвентарь NPC. Отдельно проверить смерть/оживление и езду. Сохранить логи при ошибке.
4. ASLAL и USSEP ставить отдельно из разрешённых источников в новый профиль/новую игру,
   у обоих одной версии вместе с обязательными masters. Сначала завершить выбор начала
   и перемещение офлайн, сохранить тестового персонажа, затем подключиться. Совместный сон
   в начальной камере пока не считать поддержанным сценарием.

Из-за отсутствия игровой проверки этап стабильной синхронизации пока не закрыт.
