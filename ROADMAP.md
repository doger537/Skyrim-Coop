# План разработки

Этапы выполняются последовательно. Следующий этап нельзя считать начатым, пока блокирующие проверки предыдущего не пройдены.

По новому указанию пользователя 2026-11-10 контентная проверка этапа 5 начата раньше остальных
подсистем вместе с ограниченными исправлениями этапа 2. Подключение двух игроков на базовой версии
подтверждено пользователем; новую версию ещё нужно проверить в игре. Полное ТЗ не завершено.

| Этап | Результат и условие приёмки | Статус |
|---|---|---|
| 0. Исследование | Карта сервисов, лицензий, зависимостей, версии игры и точек интеграции | Первый анализ выполнен; аудит всех транзитивных лицензий ещё впереди |
| 1. Рабочая сборка | Клиент+launcher+сервер+UI, TPTests, запуск и два клиента (A) | Собрано, TPTests пройден, сервер запущен/остановлен, клиент дошёл до главного меню; два клиента не проверены, дополнительные тесты имеют сбои — см. BUILD_STATUS.md |
| 1а. Alternate Start | Сначала ASLAL+USSEP, запасной собственный быстрый старт; два новых персонажа встречаются, одинаковый стартовый сюжет, повторный вход без повторного старта | Запланировано после рабочей сборки |
| 2. Стабильность | Базовые метрики и сценарии A/B/C/I, владение NPC, переходы, предметы, переподключение | Запланировано |
| 3. Лобби | Проверенные вход/пароль/участники/исключение/ошибки; исследование Steam без обещаний NAT | Запланировано |
| 4. Постоянный мир и дома | WorldId, сохранение и восстановление одного тестового дома (кандидат Breezehome), сундук, D/J | Запланировано |
| 5. DLC | Манифест контента, отказ или проверенный ограниченный режим, E | Запланировано |
| 6. Единые квесты | Один тестовый квест, обе стороны двигают общий прогресс, F/I/J | Запланировано |
| 7. Сюжетные NPC | Одна постоянная смерть/сцена, поздний вход, G/J | Запланировано |
| 8. Гражданская война | Одно фракционное событие, общий исход, отключаемый PvP; правила офлайн-событий | Запланировано |
| 9. Расширение квестов | Реестр проверенных заданий, адаптеры сцен и решений | Запланировано |
| 10. Выпуск | Два/четыре клиента, нагрузка, резервирование, установка, аудит прав распространения | Запланировано |

Первое минимальное изменение после этапа 1: диагностика отклонённых устаревших обновлений владения NPC
на базе существующих OwnershipEpoch и логов CharacterService; воспроизведение смены ячейки/обрыва,
сравнение до/после. Не переписывать интерполяцию без измеренного дефекта.
