# Следующая итерация после теста двух игроков

Проблема: после переключения между серверами часы клиента сохраняли отсчёт
предыдущего компьютера. Новый сервер мог иметь меньший tick (часы переставали
применяться) или больший (первый delta чрезмерно продвигал время). Дополнительный
риск NPC: команда перемещения прежнего владельца не содержала его поколения.

## Внесённые изменения

- Сетевой отсчёт сбрасывается при отключении и привязывается заново к каждому
  снимку времени. Регрессия tick восстанавливается сразу, без ожидания догоняния.
- Сервер отправляет поправку времени раз в 60 секунд; после долгой задержки
  отправляется один актуальный пакет вместо очереди пропущенных обновлений.
- Клиент плавно корректирует час по кратчайшему пути через полночь.
- Сервер принимает погоду только от текущего лидера группы с созданным персонажем.
  Она передаётся всей группе, независимо от ячейки и наличия модели лидера рядом.
  Погода повторно публикуется/запрашивается раз в минуту. Одинаковая уже применённая
  погода не вызывает повторный ForceWeather; специальная погода карты исключена.
- NotifyActorTeleport получает сетевой ID и ownership epoch. Проверки относятся
  к отслеживаемому сетевому владению; полностью неотслеживаемые статические формы
  сохраняют прежний путь размещения без истории старых поколений. Это не новый
  метод управления Havok или исправления navmesh.
- Версия контракта протокола повышена до 0x54430004. Все клиенты и сервер обновляются вместе.

Математика отсчёта, периодической отправки, перехода через полночь и политика/
сериализация teleport проверяются TPTests без игрового движка. Новые engine offsets,
хуки и методы не вводились. Игровые API вызываются по существующему пути событий,
не из фонового потока. Частота отправки ограничена; это не замер отсутствия микрофризов.

## Пять модулей: границы текущего результата

| Модуль | Состояние |
|---|---|
| Предметы/физика | Аудит выполнен. Дроп выключен флагом, полноценные динамические ID/transform/скорости не реализованы. |
| NPC/маркеры/диалоги | Добавлена защита сетевых перемещений; полный ragdoll, мебель, блокировка AI в диалоге и маркеры не реализованы. |
| Сохранение мира | В базе AE есть сохранение контейнеров/замков/квестового журнала; нет точного checkpoint обоих персонажей, NPC и физики по .ess. |
| Время/погода/сон | Исправлен отсчёт и добавлена повторная синхронизация. Общее голосование сна и строгий источник всех состояний только у хоста не реализованы. |
| Общие квесты/награды | База AE содержит журнал и admission, но пример адаптеров пуст; инициатор предметов и однократные награды обоим не реализованы. |

Проект полного решения: [HOST_AUTHORITY_DESIGN.md](docs/truecoop/HOST_AUTHORITY_DESIGN.md).
Отдельный аудит: [PHYSICS_NPC_AUDIT.md](docs/truecoop/PHYSICS_NPC_AUDIT.md).
Установленная ранее quest-relay-test2 — другой артефакт на старой базе, поэтому её
прохождение не является проверкой новых механизмов базы AE.

Нужны следующие реальные проверки: два клиента, часы после смены хоста и через
минуту, погода после карты/смены лидера, NPC после переходов и переподключения.
Проверка сборки не заменяет их. Новые сохранения и основное прохождение не смешиваются.
