# Исправление запуска CommonSE через CMD — 2026-11-13

Пользователь обнаружил Join-Path ParameterArgumentValidationErrorEmptyStringNotAllowed
в значении GamePath по умолчанию при запуске через Play-CommonSE.cmd.
Предыдущие 7 тестов передавали GamePath явно и не проверяли этот способ запуска.
Ошибка возникла до тела скрипта и перемещения CC-файлов.

Исправлено:

- GamePath вычисляется после привязки параметров, из каталога скрипта, независимо от CWD.
- Play/Restore CMD дополнительно передают абсолютный путь через собственный %~dp0.
- CMD сохраняют код ошибки PowerShell после pause.
- Исправлено аналогичное значение по умолчанию у тестового скрипта.

Windows PowerShell 5.1: 10 проверок прошли. Новые регрессии запускают отдельный PowerShell
через -File без GamePath и настоящие Play/Restore CMD из другой рабочей папки, с пробелами
в пути к искусственной игре. Вместо Skyrim запускается созданный тестом фиктивный EXE;
подтверждены его запуск и побайтовое восстановление fixture-BSA.

На ПК пользователя обновлены только три файла нашего инструмента в установленной папке
и Vortex staging. Предыдущие версии сохранены в work/ae-fix1-originals-*.
Проверены хеши, затем установленный скрипт запущен через Windows PowerShell -File с Action Plan,
без явного GamePath: определил правильную игру, 4 Creation-плагина / 8 файлов,
зависимостей-блокеров нет. Настоящая игра не запускалась, CC-файлы и сохранения не менялись.
