# Общий сюжет — проект системы

Не реализовано. Сейчас QuestService обновляет журнал игрока и рассылает изменения группе;
Party::QuestStages хранит стадии для подавления повторов в памяти. Это не долговечное состояние мира.

Будущая запись квеста: стабильный ключ плагин/локальный ID, выполненные стадии и цели,
активные цели, статус, решения, связанные NPC/aliases, маркеры уже применённых событий и наград.
Один uint16 Stage недостаточен. Нельзя выбирать «наибольшую стадию»: номера не задают
универсальный линейный порядок, ветвления и перезапуски требуют правил конкретного задания.

Сервер принимает допустимые переходы в одной ревизии общего мира. На первом прототипе важное
решение принимает лидер, взаимодействие защищается ограниченной по времени блокировкой;
обрыв освобождает её без повторного выполнения события. Действия остальных могут двигать общую цель.

Клиентский адаптер применяет поддерживаемое изменение через существующий QuestService,
подтверждает ревизию и предотвращает обратное эхо. SetStage может запускать фрагменты/сцены,
поэтому поздний вход проверяет также aliases, NPC и одноразовые эффекты. Непроверенные квесты
не получают статус поддерживаемых. Несовместимый личный сейв отклоняется без перезаписи.

Первый квест — небольшой собственный тестовый сценарий с двумя последовательными целями
и одним одноразовым последствием. После F/I/J можно адаптировать одно ванильное задание.
Гражданская война с противоположными фракциями потребует отдельного адаптера и правил завершения
проигравшей ветки: это расширение игровых правил, не простая синхронизация стадий.
