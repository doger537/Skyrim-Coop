# Проверка общего режима AE/SE — 2026-11-12

Пользователь выбрал сценарий «AE у друга, SE у меня, играем общий контент».
Реализована подготовка физически общего набора SE с обратимым исключением всех
cc*-плагинов и связанных BSA. Сетевая проверка одинакового активного контента сохранена.
Это не поддержка одновременного использования разных активных Anniversary-квестов/предметов.

Установка и точные ограничения: [AE_COMMON_MODE.md](AE_COMMON_MODE.md).

## Проверки

Windows PowerShell 5.1, искусственные TES4/MAST и BSA-файлы, 7 успешных сценариев:

1. Plan не изменяет файлы.
2. При отсутствующем launcher запуск блокируется до перемещений.
3. Плагин и BSA сохраняются вне Data.
4. Повторное включение общего режима работает.
5. Восстановление возвращает исходные байты (SHA-256 совпадает).
6. CC-зависимость другого плагина блокирует перемещения.
7. Конфликт со вновь созданным исходным файлом блокирует всё восстановление заранее,
   резервная копия не затирается и не восстанавливается частично.

Проверка установленной игры выполнена исключительно с -Action Plan: 4 CC-плагина,
8 файлов для сохранения, блокирующих MAST-зависимостей не найдено. Изменений игры,
Skyrim.ccc, Vortex, сохранений и запусков Skyrim не выполнялось.

Native-код и сетевой протокол не менялись, C++ не пересобирался. Тестовый PS-скрипт
использует фиктивный EXE с версией 1.7.104.0, не копирует игровые ресурсы и не запускает
игру. Настоящий запуск двух игровых клиентов после подготовки **не проверен**.
Этот шаг всё ещё нужен до заявления «нормально работает». Сторонние моды, loose-скрипты
и скрытые зависимости не становятся совместимыми автоматически.

## Поставка

`TrueCoop-CommonSE-Tools.zip` — дополнение к native-сборке итерации 4, не полная сборка мода.
6163 байта, 4 файла, SHA-256 каждого проверен после чтения ZIP.

SHA-256 архива: `EEA8DF017FB34DB6C208D9147E9624784977B66B2C55C51926AA73DED56B2023`.

Ставится на обоих ПК поверх одинаковой сборки через Vortex. Сервер менять не требуется,
если оба клиента и сервер уже используют одну сборку итерации 4. Следующие полные архивы
Package.ps1 также будут включать инструменты. Исходники и результаты опубликованы
в doger537/Skyrim-Coop, main; бинарный GitHub Release не создавался.
