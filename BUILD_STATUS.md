## 5. Проблемы

Компилятор выдаёт предупреждения upstream (в том числе преобразования чисел/знаковость).
Дополнительные наборы ESLoader и TiltedReverse нельзя считать пройденными. В ESLoader.cpp
BuildRecordCollection возвращает пустой RecordCollection, реальная загрузка записей закомментирована;
одно наличие файлов не доказывает, что тесты заработают. Этот код не изменялся.
Тест TiltedReverse не проверяет результаты LoadLibrary/GetProcAddress; тестовая DLL.dll/DLL_r.dll
не включена в текущие build outputs. Подмодуль не переписывался ради зелёного результата.

Address Library не найдена в проверенном Data/SKSE/Plugins. Виртуальные профили мод-менеджера
не исследовались. Обновление 2026-11-10: пользователь установил пакет через Vortex,
оба ESP и versionlib-1-7-104-0.bin обнаружены в Data. Клиент запущен до главного меню;
SkyrimTogether.exe и процессы интерфейса TPProcess.exe работают. В клиентском логе есть
Failed to create Discord instance (4); вход в меню состоялся, интеграция Discord не подтверждена.
Игровая сессия, подключение к серверу и два клиента ещё не проверены.
