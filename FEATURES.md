# Возможности и подтверждение

«Есть в исходниках» не означает «протестировано в игре».

AE-итерация 2026-11-14: [аудит и статусы A–F](docs/truecoop/ae/AUDIT.md).
Для новых функций статус **«Реализовано, игровая проверка не выполнена»**.

| Возможность | Статус |
|---|---|
| Отпечатки плагинов и runtime, причины отказа | Расширено на MAST/BSA/loose/Address Library/SKSE и отдельную схему; новая игровая проверка не выполнена |
| Каталог Anniversary Upgrade | 74 записи с плагином/BSA и статусами; реальные MAST извлекает TrueCoopContentAudit, игровых подтверждений нет |
| Повреждённые BaseId обычных и ESL-плагинов | Отказ вместо усечения к другому объекту; реализовано, игровая проверка не выполнена |
| Дубликаты Started/Stopped квеста | Сохранение истории стадий между повторными событиями группы; реализовано, игровая проверка не выполнена |
| Неизвестные ID плагинов, replay операций инвентаря, некорректное время | Исправлены конкретные случаи; не полная защита от дюпа/рассинхрона |
| Перемещение/интерполяция, NPC ownership/epochs, бой/экипировка | Есть upstream; в этой среде игровой тест не выполнен |
| Статические контейнеры/замки | SQLite commit до рассылки, восстановление после ухода всех и перезапуска/SIGKILL проверено синтетически; игровая проверка не выполнена |
| Погода, календарь, смерть/respawn NPC | Есть upstream; постоянное сохранение ещё не реализовано |
| Общий дисковый журнал квестов | Baseline, epochs, commit до рассылки и проверка сейва перед входом реализованы; это ещё не сохранение всей VM/сюжета |
| CC-адаптеры квестов | Каркас точных SHA/stages/replay/decisions реализован; реестр проверенных игровых адаптеров пуст |
| Пароль, группы, приглашения внутри сервера, исключение | Есть upstream; проверка в игре предстоит |
| Предварительная проверка среды и сценарий сборки | Реализовано в Tools/TrueCoop/Build.ps1 |
| Native-сборка клиента/launcher/сервера и production UI | Успешно собраны 2026-11-10; сервер запущен и штатно остановлен, клиент в игре ещё не проверен |
| Общий дом после перезапуска, атомарный подбор предмета | Контейнеры/замки дома сохраняются при включённом bSyncPlayerHomes; полный дом и атомарный подбор не приняты |
| Alternate Start + USSEP | Исследовано, текущая комбинация не проверена |
| Общие сюжетные решения, поздний вход с безопасным применением | Запланировано |
| Безопасные разные DLC, Steam-приглашения, общая гражданская война | Запланировано |

Подробные границы новых функций: [PERSISTENCE.md](docs/truecoop/ae/PERSISTENCE.md).
