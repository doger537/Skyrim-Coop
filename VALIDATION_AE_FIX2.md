# CommonSE fix2: активная копия и повторно появившиеся Creations

Пользователь передал ошибку друга: 74 Creation-плагина, 148 файлов и
`A backup is still active`. Старый инструмент отказывался продолжать при любом
сочетании активного backup и файлов, вновь появившихся в Data. Это мог быть
прерванный перенос, повторный Deploy или восстановление файлов другим менеджером;
точное внешнее действие по предоставленному тексту определить нельзя.

## Изменения

- Общая проверка всех записей старого журнала: имя, SHA-256, принадлежность каталогу
  игры и обе доступные копии. При отличающихся байтах — отказ до изменений файлов/журнала.
- Enable продолжает незавершённый перенос, сохраняет старые записи и добавляет новые CC.
- Идентичные дубликаты разрешены. Лишняя копия перемещается в backup/History/уникальный-ID,
  без удаления и перезаписи. Restore также принимает уже восстановленные идентичные файлы.
- Журнал заменяется через File.Replace с сохранением предыдущей версии перед переносом.
  Операция над всей группой файлов не атомарна; журнал позволяет повторить её после прерывания.
- После Restore повторно проверяются хеши. После Enable проверяется отсутствие CC-плагинов
  в Data; при повторном появлении файлов игра не запускается.
- Появился ToolsVersion fix2. Начальный вывод явно называется планом до изменений;
  окончание подтверждается CommonSE enabled и Active Creation plugins remaining: 0.

## Проверки

Windows PowerShell 5.1: **16 сценариев прошли**, включая старые проверки fix1,
прерванный перенос, идентичные дубликаты, добавление нового CC к прежнему backup,
отказ при изменённой копии без изменения журнала и неподдерживаемом имени до перемещений.
Проверен искусственный набор **74 плагина / 148 файлов**: повторное появление файлов,
повторный Enable, Restore и совпадение SHA-256 всех 148 исходных файлов.
Настоящие CMD проверены на фиктивном EXE; проверка процессов отключена только в
копии скрипта внутри тестового каталога. Production-скрипт запрет работающей игры сохраняет.

На ПК друга тесты не запускались, его файлы и журнал нам не доступны. Настоящая игра
пользователя/сервер не останавливались и не изменялись. Подключение двух игр после fix2
ещё должен проверить пользователь. C++ не менялся, native-проверки повторно не запускались.

SHA-256: `168A82A99C70A8B121EFE055D4C2293C0B5B8AC5220B94DEF737935144482C44`.

Полный архив перепакован из исходной проверенной итерации 5. Заменены только три
CommonSE-скрипта и их документация, добавлена инструкция COMMONSE_FIX2_RU.md.
Пересоздан манифест; **522 файла проверены** после повторного открытия ZIP.
Хеши неизменённых исходных файлов, включая native EXE/DLL/ESP, сверены с исходным
манифестом. Native BUILD_COMMIT остаётся **v1.8.4-32-gaa56e361**: сервер хоста
iteration5 и его клиент обновлять не требуется.

Применение при текущем сбое описано в [COMMONSE_FIX2_RU.md](COMMONSE_FIX2_RU.md).
Старую TrueCoop-CommonSE-Backup удалять нельзя. Документация и результаты
фиксируются отдельным коммитом; игровое прохождение AE с отсутствующими файлами
не объявляется безопасным. Этот режим по-прежнему предназначен для общего набора SE.
