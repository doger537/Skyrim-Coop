# Skyrim True Coop AE — пробная сборка для двух игроков

У обоих должна быть **Steam-версия SkyrimSE.exe 1.7.104.0**.
Клиенты и сервер получают один и тот же новый пакет. Точный native-идентификатор
и исходная ревизия указаны внутри архива в `TrueCoop-AE-Info/BUILD.json`.
Сервер и клиенты из разных iteration/quest-relay/resync/test-сборок не смешивайте.
Для сборки deep-coop-test дополнительно прочитайте `DEEP_COOP_TEST_RU.md` в той же папке.

1. **Верните Creations, если раньше включали CommonSE.** Закройте игру и сервер.
   В папке игры `Data/SkyrimTogetherReborn` запустите прежний `Restore-Creations.cmd`
   и дождитесь успешного восстановления. Сделайте это **до смены профиля и Deploy**.
   Папку `TrueCoop-CommonSE-Backup` не удаляйте. При ошибке изменённых файлов
   сохраните её текст и резервную копию; не заменяйте файлы наугад.

   Если прежнего инструмента нет, из нового ZIP скопируйте только
   `SkyrimTogetherReborn/Restore-AE-Creations.cmd` и весь каталог
   `SkyrimTogetherReborn/TrueCoop-Recovery` в существующую папку игры
   `Data/SkyrimTogetherReborn`. Запустите там `Restore-AE-Creations.cmd`.
   Из папки загрузок или произвольной распакованной папки восстановление не запускайте:
   инструмент определяет путь к игре по своему расположению.

2. **Подготовьте тестовый профиль Vortex — каждый у себя.** Создайте отдельный
   профиль с отдельными сохранениями. Отключите в нём старый TrueCoop / Skyrim Together
   и все CommonSE-Tools/fix1/fix2. Сохраните старые архивы для возможного отката.
   Не переносите в новый профиль основное прохождение, созданное с другим набором дополнений.

3. **Установите новый ZIP через Install From File.** Включите мод, выполните Deploy.
   В Plugins должны быть включены `SkyrimTogether.esp`,
   `SkyrimTogetherQuestPatches.esp` и `TrueCoopWorldState.esp` из одного пакета.
   Последний хранит квитанции квестовых выдач в сохранении. Он меняет отпечаток
   активного контента: не переиспользуйте старую серверную кампанию без отдельной
   миграции и не удаляйте её ради подключения. Оставьте Address Library для **1.7.104.0**.
   Проверьте одинаковый набор AE-плагинов, порядок, версии модов и игровые ресурсы
   у обоих. Выберите одинаковый язык игры: языковые BSA/strings тоже могут менять
   отпечатки. Наш пакет не содержит платных ресурсов Creations — они должны уже
   находиться в соответствующей установленной игре каждого участника.

4. **Запускайте `Play-AE.cmd`** из `Data/SkyrimTogetherReborn`. Он оставляет
   Creations активными. `Play-CommonSE.cmd` для этого профиля больше не используйте.
   Если предварительная проверка выдаёт отказ, сохраните его полный текст;
   одинаковый номер EXE сам по себе не доказывает совпадение содержимого игры.

5. **Создайте новых тестовых персонажей.** Согласуйте одинаковое начало и прогресс,
   завершите пролог офлайн и сохранитесь. Не подключайтесь во время сцены казни.
   Первый участник нового мира задаёт общий исходный журнал заданий. Сейчас реестр
   проверенных игровых адаптеров пуст: сейв с отличающимися стадиями может получить
   отказ. Все квесты автоматически догоняться или безопасно переигрываться не будут.

6. **Сервер запускает один человек через `Start-AE-Server.cmd`** в той же папке.
   Этот запуск сохраняет рабочую папку сервера и его `config` рядом с серверными
   файлами. По умолчанию база общего мира создаётся по относительному пути
   `Data/TrueCoop/world.sqlite3` внутри этой рабочей папки. Оставьте окно сервера
   открытым, подключитесь к его адресу и порту, затем создайте группу и пригласите друга.

7. **Берегите отдельный тестовый мир.** Для резервного копирования сначала завершите
   сервер командой `/quit` и дождитесь остановки. Сохраните весь его каталог
   `Data/TrueCoop` вместе с оставшимися WAL/SHM-файлами и соответствующий `config`.
   Рабочую базу кампании не добавляйте в установочный ZIP и не заменяйте ею базу друга
   ради подключения. Старый сервер нельзя запускать поверх новой кампании без
   предусмотренного отката из полной остановленной резервной копии.

Для общей загрузки лидер использует сетевой чат: `/coop-save`, затем после
сообщения «Общее сохранение №N готово» — `/coop-load N`. Оба клиента записывают
и проверяют каждый свой ESS/SKSE. F9 не заменяет эту команду. Перед первым
тестом прочитайте `docs/truecoop/PAIRED_CHECKPOINTS.md`; резервная копия пары
содержит остановленную серверную папку и соответствующие сохранения **обоих** игроков.

Для текущего продолжения проверяются исходники и компиляция клиента/сервера.
Пользователь отложил автоматические и игровые тесты; результаты прежних сборок
не подтверждают новую доставку квитанций и native gate. Политика автоматических
наград обычных квестов ещё не подключена; см. `docs/truecoop/QUEST_GRANT_DELIVERY.md`.
**Два настоящих Skyrim-клиента с этой версией ещё не проверены.** Это
экспериментальная сборка: полная работоспособность всех AE-квестов, сцен и сохранений
пока не подтверждена. Начните с подключения, движения, боя, входа в помещение и
повторного подключения на тестовых персонажах.
