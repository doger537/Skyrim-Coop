# Ограничения и открытые вопросы

Итерация 2: сравниваются только активные ESP/ESM/ESL. Разные активные DLC сейчас отклоняются,
не включают безопасный ограниченный режим. Скрипты/BSA/DLL/ресурсы вне проверки SHA-256.
Replay-фильтр не решает гонку двух РАЗНЫХ запросов на один предмет; нет транзакционного отката.
Пользователь подтвердил подключение базовой версии; игровые проверки новой версии ещё предстоят.

- Первоначальный блокер MSVC/Windows SDK снят 2026-11-10: пользователь установил VS 2022 C++
  на D:, SDK обнаружен. Автоматическое обнаружение установки с кириллицей исправлено в Build.ps1.
  Результат полной сборки и игровых проверок фиксируется отдельно; наличие компилятора не означает их прохождение.
- ESLoader_Tests: 8 из 8 тестов падают без Data/loadorder.txt; далее доступ к пустому результату вызывает SEH.
  Кроме отсутствующего набора данных, BuildRecordCollection в текущем upstream возвращает пустую коллекцию,
  а вызовы LoadFiles/BuildReferences закомментированы. Полное прохождение набора не подтверждено.
- TiltedReverse_Tests: SIGSEGV в Load the reverse dll; тест загружает DLL.dll/DLL_r.dll без проверки handle
  и вызывает найденную функцию без проверки указателя. Такая тестовая DLL не найдена в каталоге сборки.
  Исходники подмодуля не изменялись. Это отдельный сбой тестового окружения, не доказательство сбоя клиента.
- Два игровых клиента не запускались; показатели рассинхрона не измерены.
- В проверенных местах установки не найдены Address Library, ASLAL и USSEP. Профили MO2 вне Data не исследованы.
- Совпадение runtime 1.7.104.0 с main.cpp не подтверждает работоспособность всех хуков.
- Постоянное общее состояние, атомарные контейнеры, поздний вход и адаптация старых сейвов не реализованы.
- Серверный ObjectService удаляет объекты опустевшей ячейки; это необходимо учесть до обещаний постоянного дома.
- Квесты хранятся в журналах игроков/группы; нет доказательства общего сохранённого сюжета после перезапуска.
- ASLAL/USSEP: историческая совместимость с требованием старой версии; текущая комбинация не проверена.
- Root LICENSE: GPL-3.0-or-later, отдельная оговорка LGPL для launcher; package.json содержит ISC,
  а LICENSE четырёх Tilted-подмодулей — All Rights Reserved без явного разрешения распространения.
  Уведомления сохранены. Перед публичной поставкой требуется прояснить права на эти зависимости;
  общий GPL-файл не заменяет такой проверки. Полный аудит транзитивных лицензий ещё не выполнен.
- Нет оснований обещать полную совместимость произвольных DLC/модов или противоположных веток войны.
