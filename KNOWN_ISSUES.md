# Ограничения и открытые вопросы

- Клиент/сервер ещё не собраны в этой среде: MSVC/VS C++ и Windows SDK не обнаружены.
- Два игровых клиента не запускались; показатели рассинхрона не измерены.
- В проверенных местах установки не найдены Address Library, ASLAL и USSEP. Профили MO2 вне Data не исследованы.
- Совпадение runtime 1.7.104.0 с main.cpp не подтверждает работоспособность всех хуков.
- Постоянное общее состояние, атомарные контейнеры, поздний вход и адаптация старых сейвов не реализованы.
- Серверный ObjectService удаляет объекты опустевшей ячейки; это необходимо учесть до обещаний постоянного дома.
- Квесты хранятся в журналах игроков/группы; нет доказательства общего сохранённого сюжета после перезапуска.
- ASLAL/USSEP: историческая совместимость с требованием старой версии; текущая комбинация не проверена.
