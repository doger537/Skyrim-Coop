# AE у одного, SE у другого: общий режим — 2026-11-12

Обновление fix2: `SkyrimTrueCoop-iteration5-CommonSE-fix2.zip` — полная сборка с теми же
native-файлами iteration5 и исправленным CommonSE. Исправлены путь CMD (fix1) и
восстановление частично подготовленного набора/идентичных файлов, появившихся снова.
Существующую TrueCoop-CommonSE-Backup не удалять. Сервер iteration5 остаётся прежним.

Это режим **общего контента SE**, выбранный пользователем. Он не разрешает использовать
у одного активные Anniversary-предметы/квесты, которых нет у второго.

Вместо снятия сетевой проверки добавлен отдельный инструмент подготовки и запуска:
`SharedContent.ps1`, `Play-CommonSE.cmd`, `Restore-Creations.cmd`.
Native-код и протокол итерации 5 не изменялись; пересборка клиента не требуется.
Оба ПК и сервер должны использовать одну и ту же сборку TrueCoop.

## Как использовать

1. Установить один полный архив `SkyrimTrueCoop-iteration5-CommonSE-fix2.zip`
   через Vortex, включить и Deploy. Отдельный CommonSE-addon
   больше не нужен; старый основной мод и старые addon отключить в этом профиле.
2. Один раз создать отдельный профиль Vortex для совместной игры, включить отдельные
   сохранения профиля и создать **нового персонажа**. Не загружать в этом режиме старый
   сейв, использовавший удаляемые Creations. Остальные игровые моды должны совпадать у обоих.
3. Закрыть игру и открыть `Data/SkyrimTogetherReborn/Play-CommonSE.cmd` в папке Skyrim.
   Можно создать ярлык этого файла на рабочем столе. Инструмент подготовит набор и запустит
   существующий SkyrimTogether.exe; путь к игре вычисляется из расположения инструмента.
4. Для возвращения к одиночному AE закрыть игру и открыть рядом `Restore-Creations.cmd`,
   затем выбрать исходный Vortex-профиль. Перед Deploy/Purge в Vortex, проверкой файлов Steam
   или изменением DLC сначала восстанавливать Creations.

## Что именно делает инструмент

- Проверяет наличие пяти общих SE masters и поддерживаемый нашей сборкой runtime
  Steam 1.7.104.0. Другая версия exe требует одинаковой подходящей сборки у обоих,
  название купленного издания это требование не отменяет.
- Читает TES4/MAST заголовки развернутых в Data плагинов. Если сторонний плагин требует
  CC-master, блокирует применение **до первого перемещения**. Нужно отключить весь
  зависимый мод в отдельном Vortex-профиле, чтобы убрать его файлы из Data.
  Проверка консервативная: учитывает и развернутые, но выключенные в plugins.txt плагины.
- Убирает из Data все плагины cc*.esm/esl/esp и их одноимённые/текстурные BSA.
  В том числе четыре бесплатных Creation: общий режим намеренно использует базовый набор
  SE с Dawnguard/HearthFires/Dragonborn у обоих. Skyrim.ccc остаётся без изменений;
  перечисленные в нём файлы исключаются физически из Data.
- Перед первым перемещением записывает список и SHA-256 в
  `TrueCoop-CommonSE-Backup/manifest.json` в каталоге игры. Файлы сохраняет там же;
  не удаляет, не редактирует и не передаёт ресурсы между игроками.
- Enable и Restore проверяют обе копии каждого файла по сохранённому SHA-256 до начала.
  Повторно появившаяся идентичная копия допустима: лишний экземпляр сохраняется в
  `TrueCoop-CommonSE-Backup/History`, ничего не удаляется и не перезаписывается.
  При различающихся байтах скрипт останавливается. Частичный перенос можно продолжить
  повторным Play-CommonSE.cmd; новые Creations добавляются в тот же журнал. Журнал
  заменяется атомарно, предыдущий сохраняется. Сторонние скрипты/ресурсы и скрытые
  зависимости без MAST инструмент не анализирует.
- При работающей игре не перемещает файлы. Режим Plan только показывает план.

Это не автоматическая смена Vortex-профиля и не изоляция сохранений самим скриптом.
Нельзя совместить физически разные наборы для двух одновременно запущенных игр из одной Data.
В окне сначала показывается план (это ещё не результат); успешная подготовка заканчивается
`CommonSE enabled` и `Active Creation plugins remaining: 0`. В общих локациях
по-прежнему работает наша проверка одинаковых активных плагинов и их SHA-256;
оставшиеся различия модов или порядка нужно устранить в профилях.

## Основания и проверка

Upstream также рекомендует отключать Anniversary Creations для совместной игры:
https://wiki.tiltedphoques.com/tilted-online/guides/troubleshooting/disabling-the-anniversary-editions-creation-club-content

На установленной игре выполнен только **Plan**: обнаружены 4 CC-плагина и 8 файлов,
блокирующих MAST-зависимостей нет; файлы не перемещались. На искусственных TES4-файлах под
Windows PowerShell 5.1 проверены просмотр без изменений, перемещение плагина/BSA,
повторный запуск, побайтовое восстановление, запрет при CC-зависимости и запрет затирания
конфликтующего файла. Сценарии не подтверждают загрузку настоящего Skyrim после подготовки:
запуск в двух играх ещё требуется. Нулевой рассинхрон не заявляется.
