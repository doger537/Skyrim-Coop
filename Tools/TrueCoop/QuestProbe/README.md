# Single-client native quest provenance probe

The user explicitly approved this isolated gameplay test on 2026-11-18, then chose to operate the game and Vortex manually. Compilation and automated storage/protocol checks do not count as a gameplay pass.

`build_plugin.py` writes one new QUST (local ID 0x800), with a local script and no vanilla overrides, aliases, stages or start-game flag. VMAD version 5 / object format 2 and its optional fragment suffix were checked against TES5Edit's primary definitions. Start the quest explicitly and invoke `GrantForAudit` using `cqf`. Never attach the script to a real quest or load a normal character in this test.

`CompileOnly` contains handwritten declarations for just the native signatures this probe calls. These files are import declarations, not distributable Papyrus scripts: **never compile or install the base-class PEX files**.

Compiler: [Caprica v0.3.0](https://github.com/Orvid/Caprica/releases/tag/v0.3.0), release asset `Caprica.v0.3.0.7z`, SHA-256 `0037e54cf3a1021e976278d9a637e8ae541aaf9ebeb8d274b6c2cfe32f4ee559`. Install the compiler outside the repository. Compile only `Source/TrueCoopQuestGrantProbe.psc`, with `--game skyrim --ignorecwd --flags ProbeFlags.flg`, import **absolute** paths to `CompileOnly` and `Source` separated by `;`. Output must contain only `TrueCoopQuestGrantProbe.pex`. `build_plugin.py` refuses to overwrite its output.

`Package-AE.ps1 -QuestProbePath <compiled fixture directory>` opts into the diagnostic plugin and helpers. Normal packages omit them. `Start-QuestAudit.cmd` creates a unique private server/world under `%LOCALAPPDATA%/SkyrimTrueCoop/QuestAudit/run-<uuid>`, port 38649, password `questaudit`, capacity one. It sets `TRUECOOP_QUEST_AUDIT=1` only for its child processes. A journal preserves the original `SkyrimCustom.ini` bytes; the temporary settings redirect saves to a unique folder and enable Papyrus logging. Replacing the file breaks any Vortex hardlink instead of editing its other links. Closing the game collects local logs, stops only this run's server and restores the original bytes. `Restore-QuestAudit.cmd` recovers an interrupted run after the game has been closed; unexpected external INI edits or damaged backups are preserved for review.

Pass requirements: actual `after-before=17` in Papyrus, one matching local inventory source with this quest/script/function, no accidental classification of direct console gold, and ordinary execution resumes. Logs also record armed/executing thread IDs. This proves only the tested Quest-owned AddItem path. Alias/TopicInfo/Scene paths, timing cost, remote grant delivery and two-client persistence still need separate gameplay evidence. Gold from this test remains local and is not a claim of implemented shared rewards.
